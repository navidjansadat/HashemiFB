# HASHEMI FB
شبکه اجتماعی خصوصی خانواده — Made By Omar Mokhtar Hashemi

## راه‌اندازی رایگان
1. در Supabase یک پروژه رایگان بسازید.
2. فایل `supabase.sql` را در SQL Editor اجرا کنید.
3. در جدول `families` یک خانواده بسازید؛ نمونه:
   `خانواده هاشمی / HASHEMI-2026`
4. فایل `js/config.js` را با Project URL و anon public key پر کنید.
5. پروژه را روی یک سرویس استاتیک مثل Netlify یا GitHub Pages منتشر کنید.
6. اولین حساب را ثبت‌نام کنید، سپس در جدول `profiles` آن حساب را `admin` و `approved` کنید.
7. از این به بعد اعضا با Family Code ثبت‌نام می‌کنند و مدیر می‌تواند درخواست‌ها را تأیید کند.

## نکات امنیتی
- فقط `anon public key` را در فرانت‌اند قرار دهید؛ `service_role` را هرگز قرار ندهید.
- RLS در SQL فعال شده است.
- برای عکس‌ها محدودیت ۵MB در برنامه اعمال شده است.
- برای استفاده واقعی، تأیید ایمیل و محدودیت‌های Auth را در Supabase فعال نگه دارید.

## PWA
سایت دارای `manifest.json` و service worker است. پس از HTTPS، در Chrome گزینه Add to Home Screen قابل استفاده است.

## محدودیت نسخه
ذخیره موقعیت مکانی، اعلان Push واقعی و تماس صوتی/تصویری در این نسخه پایه پیاده نشده‌اند؛ معماری پروژه برای افزودن آنها آماده است.
